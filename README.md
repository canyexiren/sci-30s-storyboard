# 30 秒科普拟人分镜生成器

> 把任意科普文案压成 **30 秒 / 6 个镜头**的 AI 视频分镜提示词，固定形态为「外国真人主讲 + 拟人化生物配合解说」，每条画面描述可直接粘贴进 Sora / 可灵 / 即梦 / Midjourney。

一个 DSH / Claude Skill（纯提示词，无运行时依赖）。

---

## 它解决什么问题

科普文案直接丢给 AI 视频工具，出来的东西通常有三种毛病：

1. **没有时间轴**——文案是文章逻辑，不是镜头逻辑，30 秒塞不进 300 字。
2. **画面描述是空的**——"一只章鱼在深海里"，模型只能给你一只漂着的章鱼，没有光影、没有景别、没有动作。
3. **拟人角色崩坏**——要么低幼卡通把硬核科普拍成动画片，要么拟人化过头长出了人腿。

这个技能把三件事写死：镜头数与时长的硬约束、画面提示词的四段结构、拟人化的尺度边界。

## 效果示例

输入一段埃及考古文案，输出（节选）：

```markdown
**镜头3（10-16s）**
- 对应文案：法老之所以要在通往冥界的旅途上带一把瓜子
- 画面提示词：主体——拟人化西瓜籽（棕黑硬壳、细小四肢、认真表情）悬浮半空，
  抱着一只迷你皮水囊，对镜头点头、抬手比划｜场景——背景虚化的墓室壁画，
  冥界审判图隐约可见，浮尘缓慢飘动｜镜头语言——近景，固定镜头，轻微呼吸感｜
  画质风格——半写实拟人，材质保留硬壳质感，柔光轮廓，电影级写实质感，8K 超清，
  9:16 竖屏，画面无任何文字
- 解说台词：法老通往冥界的路上，为什么非要带上它
```

完整 6 镜见 [`references/example-watermelon.md`](references/example-watermelon.md)。

## 安装

技能目录是纯文件约定，克隆到 DSH 的 skills 目录即可：

```bash
git clone https://github.com/canyexiren/sci-30s-storyboard.git ~/.dsh/skills/sci-30s-storyboard
```

Windows PowerShell：

```powershell
git clone https://github.com/canyexiren/sci-30s-storyboard.git "$env:USERPROFILE\.dsh\skills\sci-30s-storyboard"
```

也可以直接复制 `SKILL.md`——最小可用形态只有一个文件，`references/` 和 `scripts/` 都是按需加载的可选项。

Claude Code 用户放到 `~/.claude/skills/sci-30s-storyboard/`。

## 用法

不需要命令，把文案丢进来就行：

> 帮我把这段做成 30 秒分镜：章鱼有三颗心脏，两颗鳃心把血送进鳃里换氧，一颗主心把血送到全身。但主心在章鱼游泳时会停止跳动……

技能按 description 命中后自动执行：取叙事节点 → 切 6 镜锁 30 秒 → 定角色 → 逐镜填四要素 → 台词配字数 → 自检。

### 输出规格

| 项 | 值 |
|---|---|
| 总时长 | 30 秒（硬约束） |
| 镜头数 | 6（硬约束） |
| 单镜时长 | 4–6 秒，首尾相接合计 30 |
| 主讲人 | 外国真人，身份随主题匹配，全片不换人 |
| 拟人角色 | 只拟人化文案里真实出现的事物，中度拟人、写实不低幼 |
| 每镜四要素 | 编号+时长 / 对应文案 / 画面提示词 / 解说台词 |

## 自检脚本

交付前跑一遍，机器核对时长、镜头数、四要素、台词字数：

```bash
python3 scripts/check_storyboard.py your-storyboard.md
```

```
shots        : 6
total        : 30s
durations    : 0-5s, 5-10s, 10-16s, 16-21s, 21-26s, 26-30s
RESULT: PASS (0 warning)
```

检查项：镜头数与编号、时长合计、时长连续性、单镜区间、四要素齐全、台词字数与时长匹配（中文口播 4–5 字/秒）、负面词存在。有 FAIL 返回退出码 1。

## 可调项

默认 6 镜 30 秒竖屏。要求 8 镜、45 秒、横屏 16:9、换主讲人性别年龄，直接说，技能会按你的规格覆盖默认值并在交付首行标注偏离。
