# 提示词词库

画面提示词写不动的时候从这里取词。用法：每镜抽 1 个景别 + 1 个运镜 + 1 个光影 + 固定风格后缀，别堆词。

## 1. 景别

| 景别 | 用在哪 | 写法 |
|---|---|---|
| 大远景 / 全景 | 开篇钩子、环境交代 | 全景，人物占画面 1/3 以下 |
| 中景 | 主讲人讲解、双人/双角色同框 | 中景，半身入画，背景可辨 |
| 近景 | 拟人角色登场、表情反应 | 近景，胸口以上，浅景深 |
| 特写 / 微距 | 关键证据（瓜子、水珠、纹路） | 特写，填充画面 70% |
| 过肩 / 主观 | 引导视线看向发现物 | 过肩镜头，前景虚化肩部 |

## 2. 运镜

| 运镜 | 效果 | 写法示例 |
|---|---|---|
| 推 | 强调、压迫、揭示 | 缓推至特写／急推制造冲击 |
| 拉 | 收束、揭示全貌 | 缓拉，末帧留白 |
| 摇 | 展示空间关系 | 横摇扫过墓室四壁 |
| 移 / 跟 | 伴随主体移动 | 横向跟拍滚动的西瓜 |
| 升降 | 尺度感 | 无人机式升镜，拉出荒漠全貌 |
| 固定 | 稳定讲解、克制 | 固定镜头，轻微呼吸感 |
| 环绕 | 展示立体结构 | 半环绕 30°，绕拟人角色一周 |

## 3. 光影

| 光影 | 情绪 | 适用 |
|---|---|---|
| 暖金侧光 | 史诗、珍贵 | 墓室、黄金、日落 |
| 冷蓝顶光 | 科学、冷静 | 实验室、显微、深海 |
| 手电筒硬光 | 探索、未知 | 洞穴、遗迹、夜间 |
| 逆光轮廓 | 神秘、留白 | 角色登场、结尾 |
| 顶光硬阴影 | 压迫、干旱 | 荒漠正午 |
| 柔光漫射 | 亲和、讲解 | 拟人角色近景 |
| 体积光 / 丁达尔 | 神圣、尘埃感 | 密闭空间开门的瞬间 |

## 4. 固定风格后缀（每条提示词都带）

```
电影级科普纪实质感，8K 超清，杜比光影，写实渲染，色调统一高级，9:16 竖屏，画面无任何文字
```

需要变体时只换色调词：暗金色调（遗迹）／冷青色调（科学）／暖褐色调（历史）／高饱和自然绿（生态）。

## 5. 负面词（整片统一，可每镜尾部重复）

```
无文字，无字幕，无水印，无 LOGO，无中文标识；
人物五官自然，五指正常，无多肢少肢；
生物结构准确，无多余眼睛与口器；
不模糊，无低像素，无色溢出，无过曝欠曝；
非卡通，非 Q 版，非表情包，非塑料感；
无文案之外的剧情、人物与场景
```

## 6. 拟人化尺度表（决定"写实"还是"低幼"）

| 维度 | 可做 | 不可做 |
|---|---|---|
| 外形 | 保留本体轮廓、材质、颜色、比例 | 换成圆头大眼卡通体 |
| 表情 | 眼、口、眉的细微拟人表情 | 夸张表情包脸 |
| 肢体 | 加细小手/足，做手势与持物 | 长出人腿人臂走秀 |
| 动作 | 点头、比划、演示、递物 | 跳舞、卖萌、翻跟头 |
| 说话 | 口型微动，配旁白 | 大段对白抢主讲人戏 |
| 质感 | 写实渲染、真实光照、正确景深 | 贴纸感、发光描边、赛璐璐 |

一句话标准：**观众相信它是那个生物，只是会做表情、会打手势。**

## 7. 30 秒节奏配方（6 镜）

| 镜 | 时长 | 职能 | 常见画面 |
|---|---|---|---|
| 1 | 5s | 钩子：反差/悬念 | 开门、巨物、反常细节 |
| 2 | 5s | 抛出反常识对象 | 特写关键物，与预期形成对比 |
| 3 | 6s | 拟人角色登场提问 | 近景，角色对镜头 |
| 4 | 5s | 机制/原因 | 全景环境，讲清因果 |
| 5 | 5s | 反转/证据 | 推镜，物证出现 |
| 6 | 4s | 悬念收口 | 拉镜留白，抛下一条的问题 |

变体：信息密度高的题材可把 3、4 镜各减 1 秒挪给 5 镜，但六镜合计必须仍是 30。
