# 成品示例：埃及法老的西瓜子（6 镜 / 30 秒）

对照用。密度标准：每镜画面提示词 60–90 字，四段齐全；台词 18–26 字。

## 角色设定

- 主讲人：埃及考古学家，外国中年男性，探险工装 + 手电筒，全程同一人。
- 拟人角色：①西瓜籽（棕黑硬壳，细小四肢，抱迷你水囊，认真表情）②野生西瓜（饱满青皮，会眨眼，表皮挂水珠）。

---

**镜头1（0-5s）**
- 对应文案：推开埃及法老的墓门，在满世黄金里
- 画面提示词：主体——埃及考古学家（外国中年男性，卡其探险工装，手持手电筒）双手推开厚重石门，肩背绷紧，尘埃在光柱里翻涌｜场景——法老墓室内部，四壁堆满黄金面具与器皿，金光反射在石壁上，幽暗封闭空间｜镜头语言——全景，缓推镜头由门口推向墓室深处｜画质风格——电影级科普纪实质感，8K 超清，杜比光影，写实渲染，暗金色调，9:16 竖屏，画面无任何文字
- 解说台词：推开法老的墓门，满室黄金，一眼望不到头

**镜头2（5-10s）**
- 对应文案：你会发现一件寒碜的陪葬品，一小篮精心封存的西瓜子
- 画面提示词：主体——考古学家蹲下，手电光束收窄打在角落藤篮上，他皱眉伸手轻触篮沿，指尖悬停｜场景——藤篮里整齐码着黑褐色西瓜子，与四周耀眼金器形成强反差，地面细沙与碎金屑｜镜头语言——中景转特写，固定后缓推至瓜子特写｜画质风格——电影级科普纪实质感，8K 超清，暖黄硬光，浅景深，写实渲染，9:16 竖屏，画面无任何文字
- 解说台词：藏着一件最寒酸的陪葬品——一小篮西瓜子

**镜头3（10-16s）**
- 对应文案：法老之所以要在通往冥界的旅途上带一把瓜子
- 画面提示词：主体——拟人化西瓜籽（棕黑硬壳、细小四肢、认真表情）悬浮半空，抱着一只迷你皮水囊，对镜头点头、抬手比划｜场景——背景虚化的墓室壁画，冥界审判图隐约可见，浮尘缓慢飘动｜镜头语言——近景，固定镜头，轻微呼吸感｜画质风格——半写实拟人，材质保留硬壳质感，柔光轮廓，电影级写实质感，8K 超清，9:16 竖屏，画面无任何文字
- 解说台词：法老通往冥界的路上，为什么非要带上它

**镜头4（16-21s）**
- 对应文案：是因为在干旱的死亡国度里，再多黄金也换不来一口水
- 画面提示词：主体——考古学家站在沙丘顶端，仰头倒举空水壶，只滴下一滴；脚下沙地里散落金器无人问津｜场景——烈日下的埃及荒漠，龟裂地表，热浪扭曲远景，天空惨白｜镜头语言——广角全景，固定镜头，人物居左下三分线｜画质风格——亮调强光，高对比，颗粒感纪实，电影级质感，8K 超清，9:16 竖屏，画面无任何文字
- 解说台词：因为在干旱的死亡之地，黄金换不来半口水

**镜头5（21-26s）**
- 对应文案：但这颗西瓜能
- 画面提示词：主体——一颗饱满野生西瓜从沙丘后滚出，拟人化地眨了下眼，青皮上渗出细密水珠；考古学家惊喜蹲身，双手接住｜场景——沙丘背风面，午后侧光，沙粒被风掀起｜镜头语言——特写推至中景，跟随西瓜滚动的横向跟拍后固定｜画质风格——侧逆光勾勒瓜皮绒毛，水润高光，电影级写实，8K 超清，9:16 竖屏，画面无任何文字
- 解说台词：但一颗西瓜，就是一座会走路的活水窖

**镜头6（26-30s）**
- 对应文案：承接悬念，引出下文
- 画面提示词：主体——考古学家与拟人西瓜并肩站在沙丘上，西瓜抬手做出"请"的引导手势，一人一瓜望向远方｜场景——绵延的非洲荒原，落日压在地平线，长影投在沙脊上｜镜头语言——中景，缓拉镜头，末帧留白给下一条视频｜画质风格——暖金色调收尾，柔和逆光，电影级质感，8K 超清，9:16 竖屏，画面无任何文字
- 解说台词：这颗瓜，怎么从剧毒野果变成夏日神果

## 这段示例做对了什么

1. **首镜钩子**：暗门 + 金光，5 秒内给足反差。
2. **拟人角色延迟登场**：第 3 镜才出现，且只拟人化文案里真实存在的西瓜籽，不抢主讲人的戏。
3. **每镜四段齐全**：主体、场景、镜头语言、画质风格，没有一句"好看的画面"。
4. **时长连续**：0-5 / 5-10 / 10-16 / 16-21 / 21-26 / 26-30，合计 30。
5. **台词字数贴合**：5 秒镜 20 字上下，4 秒镜 17 字上下。
6. **负面项内嵌**：每条尾部都有"画面无任何文字"，避免 AI 生成乱码字幕。
